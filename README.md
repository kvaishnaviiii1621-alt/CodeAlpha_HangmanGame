# CodeAlpha Hangman Game
## Project Description
This project is a simple text-based Hangman game developed using Python as part of the CodeAlpha Python Programming Internship.

The player has to guess a randomly selected word one letter at a time. The game allows a maximum of six incorrect guesses.
## Features
- Contains 5 predefined words
- Randomly selects a word
- Allows the player to guess one letter at a time
- Provides feedback for correct and incorrect guesses
- Allows a maximum of 6 incorrect guesses
- Displays win or game-over messages
- Handles repeated and invalid inputs
## Technologies Used
- Python
- Random module
- Lists
- Strings
- Loops
- Conditional statements
- User input
## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run: python hangman.py
6. Start guessing the letters and do enjoy the game.
